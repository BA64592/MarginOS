# Decisions locked (v16.4)

**MarginOS Spec Amendment v16.4** — Free data kept for 24 hours; original files deleted after import.  
Approved by Akthar Uddin, 29 October 2026 (incl. K8–K11).

| ID | Decision |
| --- | --- |
| **F1** | Free data deleted **24 hours** after each successful upload (own clock per upload). Sample data has no clock. No reminder email. |
| **F2** | Notices: before upload, deletion time after import, time left on results, last-hour warning + export/upgrade, post-deletion message. |
| **F5** | Original uploaded files deleted after import succeeds, fails or is cancelled (Free and Pro). Unfinished imports cancelled after 1 hour. |
| **F7** | Upgrade to Pro within 24 hours **cancels** clocks and keeps Free data. Delayed payment **pauses** clocks (K11). |
| **K8** | Refunded / charged-back Pro: data kept until Start fresh or account deletion; **export only** while not Pro; restored if Pro returns; 24-month inactivity rule applies. |
| **K9** | Free still **3 uploads / day**. Re-upload after 24h counts as one. |
| **K10** | Sales wording approved; privacy line pending legal review. |
| **K11** | Clocks pause during pending delayed payment; unfinished imports cancelled after 1 hour; Free accounts kept. |
